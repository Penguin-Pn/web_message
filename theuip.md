# theuip
This file format is designed for themes in the **penguin web Messaging** system.  
This file format includes colors and dark/light mode, and may contain other information such as characters that are different in different languages ​​in this messenger.   
The name **theuip** stands for **theme user internal for penguin web Messaging**. 
This format is in json compressed with zlib.  
**This is a proprietary format and the parser for this format is only included in the project code.**
